**Восстановление из бекапа (рекомендуется):**
1. Скачайте последнюю версию AmneziaVPN для вашей системы:
   [GitHub Releases](https://github.com/amnezia-vpn/amnezia-client/releases)
2. Установите и запустите приложение
3. Нажмите "Приступить"
4. Выберите "Восстановить из резервной копии"
5. Выберите скаченный файл бекапа из бота
6. Подключитесь. Подклоючение может занимать до одной минуты.
📖 Подробная инструкция с картинками: https://telegra.ph/Instrukciya-AWG-Phonr-04-24
